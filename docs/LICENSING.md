## The Windows App SDK question

GPL v3 requires that whoever distributes the program also offers the Corresponding Source of everything the program
needs to run, except "System Libraries". The Windows App SDK is bundled inside `NOXEL.exe` and is proprietary, and
it does not clearly qualify as a System Library.

* **For reprinted (the copyright holder):** not a problem. You can distribute your own code with any components you
  are allowed to redistribute, and Microsoft's terms allow redistributing it inside applications.
* **For anyone else redistributing NOXEL binaries or a modified version:** strictly, plain GPL-3.0-only doesn't
  grant permission to ship it with a proprietary non-system library.

The usual remedy is an *additional permission* under GPL v3 section 7, for example:

> Additional permission under GNU GPL version 3 section 7: If you modify this Program, or any covered work, by
> linking or combining it with the Microsoft Windows App SDK, the Microsoft .NET runtime or the Microsoft Edge
> WebView2 runtime (or modified versions of those libraries), containing parts covered by the terms of their
> respective licenses, the licensors of this Program grant you additional permission to convey the resulting work.

Adding it changes the license expression from `GPL-3.0-only` to `GPL-3.0-only WITH` a custom exception. It is
**not** added yet. It's the copyright holder's decision, ideally with legal advice. Microsoft's terms also forbid
putting *their* source code under a copyleft license. NOXEL doesn't do that: their components keep their own
licenses.
